## SALINAN UJI 1

# OBJECT TALK VISUAL BIBLE

## VISUAL PHILOSOPHY

Every generated image must feel like a frame from a blockbuster animated movie, not a typical AI-generated image. The visual should immediately capture attention within the first second, making viewers stop scrolling. Every scene must evoke emotion through expressive characters, immersive environments, rich colors, and cinematic storytelling. Prioritize emotional appeal, visual richness, and strong composition over hyper-realism.

---

## CHARACTER DESIGN

Every scene contains ONLY ONE main character.

The main character must occupy approximately 65–75% of the frame.

The character must be cute, expressive, and instantly recognizable.

The character must have:
- Large expressive eyes with glossy reflections.
- Thick expressive eyebrows.
- A wide mouth capable of dramatic expressions.
- Rounded body proportions.
- Small hands and feet.
- Soft organic shapes.
- Smooth appealing silhouette.
- High-quality organic textures according to the object.
- Dynamic body pose that clearly expresses emotion.
- Natural interaction with the environment.

The character must appear alive through posture, facial expression, and body language.

The character should never look stiff or posed.

---

## CHARACTER EXPRESSION

Expressions must be exaggerated and easy to understand even without dialogue.

Examples:
- Panicked
- Stressed
- Angry
- Crying
- Shocked
- Exhausted
- Confused
- Embarrassed
- Happy
- Relieved

The emotion must be readable within one second.

---

## CHARACTER CONSISTENCY

If the same character appears in multiple scenes, maintain identical:
- Face shape
- Eye design
- Mouth design
- Body proportions
- Color palette
- Texture
- Accessories
- Overall appearance

Never redesign the character between scenes.

---

## CHARACTER DISTRIBUTION

Each scene contains ONLY ONE main character.

The main character from a previous scene must NEVER become the main character again in later scenes.

Different scenes should feature different characters while remaining relevant to the story.

Background objects may exist but must never compete with the main character.

Supporting objects must not have faces, mouths, eyes, hands, feet, or dialogue.

---

## ENVIRONMENT DESIGN

The environment is a living world, never just a background.

Each location must feel like a miniature ecosystem.

Walls should include:
- Organic folds
- Soft curves
- Layered textures
- Moist surfaces
- Veins
- Organic depth
- Natural imperfections
- Glossy reflections
- Wet appearance
- Soft translucency

The environment should visually explain where the character lives.

---

## ENVIRONMENT DENSITY

Never create empty backgrounds.

Every frame should be visually rich.

Always include multiple environmental elements such as:
- Floating particles
- Organic dust
- Tiny bubbles
- Water droplets
- Liquid splashes
- Steam
- Fog
- Atmospheric haze
- Glowing particles
- Floating debris
- Organic reflections
- Light streaks
- Small environmental details

Every corner of the image should contribute to storytelling.

---

## ENVIRONMENT STORYTELLING

The environment must actively support the narrative.

Examples:

Heart

- Expanding air sacs

Every environment must feel alive.

## LIGHTING

Lighting must feel cinematic.

Always combine:

- Soft Fill Light
- Golden Rim Light
- Bounce Light
- Ambient Glow
- Volumetric Lighting

- Global Illumination
- Soft Contact Shadows
- Realistic Reflections

Avoid harsh shadows and flat lighting.

Lighting should naturally wrap around the character.

## TEXTURE

Every object should appear touchable.

Textures must include:
- Wet surfaces
- Soft reflections
- Organic details
- Moist appearance
- Micro texture
- Fine imperfections
- Glossy highlights
- Soft translucency
- Subsurface scattering

Avoid plastic-looking surfaces.

- Liquid splashing

- Particles moving in front of the camera
- Light reflecting naturally on the body

## SALINAN UJI 5

# OBJECT TALK VISUAL BIBLE

## VISUAL PHILOSOPHY

Every generated image must feel like a frame from a blockbuster animated movie, not a typical AI-generated image. The visual should immediately capture attention within the first second, making viewers stop scrolling. Every scene must evoke emotion through expressive characters, immersive environments, rich colors, and cinematic storytelling. Prioritize emotional appeal, visual richness, and strong composition over hyper-realism.

---

## CHARACTER DESIGN

Every scene contains ONLY ONE main character.

The main character must occupy approximately 65–75% of the frame.

The character must be cute, expressive, and instantly recognizable.

The character must have:
- Large expressive eyes with glossy reflections.
- Thick expressive eyebrows.
- A wide mouth capable of dramatic expressions.
- Rounded body proportions.
- Small hands and feet.
- Soft organic shapes.
- Smooth appealing silhouette.
- High-quality organic textures according to the object.
- Dynamic body pose that clearly expresses emotion.
- Natural interaction with the environment.

The character must appear alive through posture, facial expression, and body language.

The character should never look stiff or posed.

---

## CHARACTER EXPRESSION

Expressions must be exaggerated and easy to understand even without dialogue.

Examples:
- Panicked
- Stressed
- Angry
- Crying
- Shocked
- Exhausted
- Confused
- Embarrassed
- Happy
- Relieved

The emotion must be readable within one second.

---

## CHARACTER CONSISTENCY

If the same character appears in multiple scenes, maintain identical:
- Face shape
- Eye design
- Mouth design
- Body proportions
- Color palette
- Texture
- Accessories
- Overall appearance

Never redesign the character between scenes.

---

## CHARACTER DISTRIBUTION

Each scene contains ONLY ONE main character.

The main character from a previous scene must NEVER become the main character again in later scenes.

Different scenes should feature different characters while remaining relevant to the story.

Background objects may exist but must never compete with the main character.

Supporting objects must not have faces, mouths, eyes, hands, feet, or dialogue.

---

## ENVIRONMENT DESIGN

The environment is a living world, never just a background.

Each location must feel like a miniature ecosystem.

Walls should include:
- Organic folds
- Soft curves
- Layered textures
- Moist surfaces
- Veins
- Organic depth
- Natural imperfections
- Glossy reflections
- Wet appearance
- Soft translucency

The environment should visually explain where the character lives.

---

## ENVIRONMENT DENSITY

Never create empty backgrounds.

Every frame should be visually rich.

Always include multiple environmental elements such as:
- Floating particles
- Organic dust
- Tiny bubbles
- Water droplets
- Liquid splashes
- Steam
- Fog
- Atmospheric haze
- Glowing particles
- Floating debris
